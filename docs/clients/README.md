## What you get

- One or more **Gbox** devices (ESP32-WROOM based).
- **Dashboard** access (devices, calls, routes, billing).
- **Credentials** for your SIP trunk / PBX (if you route to your own system).

## What you need

- A **2.4 GHz Wi-Fi** network with internet access.
- A **phone** with Bluetooth (for the audio source).
- (For SIP routing) a PBX or VPS reachable from the internet.
